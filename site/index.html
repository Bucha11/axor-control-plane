How it works

1 · CATCH

Break a tool. Read the receipt.

An observe-only proxy fronts your tools (auth passes byte-for-byte, raw bodies never stored). Inject a fault; the audit compares what happened against what the agent claimed. The mismatch is an EvidenceCase — shareable, exportable, revocable.

2 · REPLAY

Question any run, deterministically.

Scrub the recorded trace; fork counterfactuals ("no exec capability", "this value arrives tainted", "budget = N") and see the first step that diverges. No model call. A provenance graph traces every value.

3 · GOVERN

Live fleet, real interventions.

Wrap the agent in axor-core and it's a live node: pause, budget-cap (decrease-only), cascade-stop the subtree. Commands are Ed25519-signed; the adapter verifies with its own keys. Axor down ⇒ agent unaffected.

4 · REGRESS

CI for governance configs.

Pin caught attacks (must-block) and legit flows (must-pass); replay the corpus under a candidate policy. Two-sided, so a config that blocks everything fails honestly.

What the security reviewer asks first

What does the proxy see?

Observations only: tool, status, sizes, SHA-256 hashes. Raw request/response bodies are never persisted. Authorization passes through byte-for-byte — never parsed, never stored.

What if Axor goes down?

Nothing happens to your agent. The plane is an advisory overlay: enforcement lives in the adapter with its own config and keys. A compromised backend cannot forge operator commands.

Is safety paywalled?

No, structurally: anything that answers "is my agent safe" is Apache-2.0, forever. Orgs pay for fleet features (SSO, compliance reports, hosted). The EE license check itself is offline Ed25519 — it never phones home.
